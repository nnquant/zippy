日期：2026-09-22。推进 F14/F22/F29；原审计仍为 **25/34 已关闭、9 项开放**。
本批删除主包中可由独立客户端直接接替的基础实现；主包订阅仍依赖旧 Session/SHM 发布器，
没有把基础层收敛描述为完整订阅或旧服务权威已经退出。

## 单一实现与实际修复

主包删除独立时间正则及 14 个重复类/函数，改用 `zippy_client` 的 Row、col/lit、表达式
参数规约、JSON 序列化和时间过滤规约。同一个表达式不再经过两套时间字符串解释。
主包剩余 Gateway 解码/查询解释器、本地查询与生产者入口继续纳入后续删除范围。

核查发现独立客户端此前会接受混合日期分隔符、月份后直接带时分，并将部分错误输入解释为
整个月范围；`$` 结尾还可能接受尾随换行。现在使用完整匹配，日期分隔符保持一致，带时间
必须有完整日期，小数最多九位，时区分钟不得超过 59、小时不得超过 23。
非比较表达式不进入时间比较规约，避免反向算术表达式触发错误的运算符映射。

时间仍按列声明时区解释，未声明时使用 UTC；按当地日历解析的日期在 DST 切换日保持
23/25 小时区间。datetime 子类若声明纳秒余数，保留余数而不读取单位可能变化的 `.value`；
无时区子类使用列时区，与普通 datetime 一致。测试覆盖这一通用子类契约；本机未安装
pandas，现有可选 pandas 测试仍跳过，没有将其描述为真实 pandas 版本矩阵验收。

Row 统一为客户端 Mapping 类型。主包 Parquet 行重放与旧远端 Arrow 行解码使用相同转换：
timestamp 返回其 schema 声明单位下的整数，保留负值、纳秒及空值，不先转 Python datetime。
表回调仍保留原 Arrow schema 和数据；调用者需要 datetime 时显式转换。原重放测试保留并
更新为整数时间戳契约，没有通过删除这些行为断言来规避变更。
